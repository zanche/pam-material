# pam-material

Aulas e listas de exercícios da disciplina **Programação para Aprendizagem de Máquina** (Especialização em Ciência de Dados, CIn-UFPE). Professor: Cleber Zanchettin.

## Como usar

1. Clique em **abrir no Colab** na aula do dia.
2. No Colab, use **Arquivo › Salvar uma cópia no Drive**. Sem isso, o que você fizer não fica guardado.
3. Trabalhe na sua cópia: substitua cada `...` pelo seu código e rode as células de conferência ✅.
4. Antes de entregar uma lista, use **Ambiente de execução › Reiniciar sessão e executar tudo**.
